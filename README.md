# Pentagon Cyber Defense

Private security assessments for businesses that cannot afford a public incident — or an unreliable fixer.

**Live website: [https://miracleomokaro.github.io/](https://miracleomokaro.github.io/)**

Pentagon is a founder-operated cybersecurity company. We run private, scoped reviews of what a business actually runs — site, cloud, email, payments — then hand over a clear, ordered fix plan. No public listing of your systems. No enterprise catalogue. Price is fitted to the stage you are in.

## What we do

1. **Scope** — map what you run and agree a private engagement  
2. **Assess** — find the holes that matter  
3. **Report** — named issues, severity, exact fix order  
4. **Fix path** — stay with the remediation plan  

Documents we sign: NDA, MSA, SOW, SLA.
